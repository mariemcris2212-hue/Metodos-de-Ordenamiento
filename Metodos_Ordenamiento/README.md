Alumno: Mariem Cristina Garcia Lopez

Repositorio correspondiente a la Unidad 5 de la asignatura Estructura de Datos

## Descripción de la Práctica
Programa desarrollado en Java que implementa el algoritmo clásico de ordenamiento por burbuja. El código cuenta con la optimización de bandera (`intercambiado`) para detener las iteraciones de manera anticipada si el arreglo ya se encuentra ordenado, y está estructurado en un paquete modular.

## Requisitos del Entorno
- Java JDK (versión 8 o superior).
- Una terminal de comandos (CMD, PowerShell, terminal de VS Code o IntelliJ IDEA).

## Instrucciones de Clonación, Compilación y Ejecución

1. Clonar el repositorio:
   Abre tu terminal y ejecuta el siguiente comando:
   ```bash
   git clone https://github.com/mariemcris2212-hue/Metodos-de-Ordenamiento.git

2. Navegar a la carpeta del código fuente (src):
   cd ruta-del-repositorio/src

3. Compilar las clases en Java:
   javac Metodos_Ordenamiento/Burbuja.java Metodos_Ordenamiento/Main.java

4. Ejecutar el programa:
   java Metodos_Ordenamiento.Main

## Salida esperada en consola
Al ejecutar el programa, se mostrará en pantalla tanto el arreglo original desordenado como el arreglo resultante ya ordenado de forma ascendente:

Arreglo original:

[6, 1, 5, 8, 3, 2, 7, 4]

Arreglo ordenado:

[1, 2, 3, 4, 5, 6, 7, 8]
